Player12 — Windows portable edition

1. Extract the entire ZIP into a folder on your computer.
2. Open that folder and double-click Player12.exe.
3. Choose New Game and start your career.

Keep Player12.exe, the assets folder and licences together. Run the extracted
copy; launching an executable directly inside the ZIP cannot find its data.
No compiler, development tools or separate VC++ redistributable are required
by the default portable build.

Saves, settings, screenshots and logs are kept in:
  %APPDATA%\FlavioMili\FootballManagement

The historical folder name is retained so earlier careers remain available.
You may move the extracted game folder without moving your saves.

Source, documentation and issue reports:
  https://github.com/FlavioMili/FootballManagement

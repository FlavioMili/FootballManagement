Detailed Description

One honour given in a league.

Manager awards name the club (player_id 0). The player's name is kept because winners retire and leave the database. value/count depend on the award: average rating and appearances (player awards), goals and minutes (Golden Boot), clean sheets and appearances (Golden Glove), points above expectation and matches (manager awards), goal minute (Goal of the Month).

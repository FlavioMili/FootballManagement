Detailed Description

A news item for the managed club.

Title and body are stored as language keys plus arguments so that messages follow the current UI language. Arguments starting with '@' are themselves language keys (e.g. "@INJURY_HAMSTRING_STRAIN"). Use formatTitle() and formatBody() to obtain display text.

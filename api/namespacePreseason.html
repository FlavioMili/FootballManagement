Detailed Description

Pricing of camps and tours.

A week-long camp between the first and second friendly sharpens the squad (match fitness), drills the tactic and bonds the group; abroad it costs more and does more. Tour matches abroad earn an appearance fee that grows with the club's income and the opponent's stature, minus travel; two tour matches in a season add a reputation point. [P]

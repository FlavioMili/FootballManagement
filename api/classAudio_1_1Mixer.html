Detailed Description

Real-time stereo mixer (48 kHz, interleaved float): the crowd bed plus a fixed pool of one-shot voices, routed through crowd and effects buses into the master bus and a soft limiter, so output never leaves [-1, 1].

Threading: the control methods (trigger, setLevels, setCrowd) are called from one producer thread (the UI thread) and render() from the audio thread. They only exchange plain data through atomics and a single- producer/single-consumer command ring; render() never allocates or locks.

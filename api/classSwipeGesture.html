Detailed Description

Recognises a two-finger sideways swipe from wheel samples.

Fed with each wheel sample (dx > 0: the fingers moved right), it reports one step per gesture once the sideways travel passes the threshold, and then ignores the rest of that gesture. A gesture that starts vertically is a page scroll and is ignored until it ends; so is one that drifts into a vertical scroll. A pause longer than the idle gap starts a new gesture.

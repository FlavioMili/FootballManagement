Detailed Description

Navigation between management screens.

Sections replace whatever is stacked above the club dashboard (one routine screen at a time, no overlay pile-up). Detail screens such as a player profile stack on top of the current section. Every screen shown is recorded in the view's history (GUIView::navHistory()), which Back and Forward walk like a browser's.

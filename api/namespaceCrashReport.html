Detailed Description

Local crash reports. A fatal signal, an uncaught exception or an error reaching main() writes <logs>/crash-<utc>.txt (version, build, reason and, where available, a backtrace) and marks it pending; the next start shows a notice and keeps the crashed session's log next to it as crash-<utc>.log. Reports stay on this computer: nothing is ever sent anywhere.

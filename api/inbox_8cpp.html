◆ formatLocalized()

std::string formatLocalized ( const std::string &  key,
const std::vector< std::string > &  args 
)

Formats a localised template, substituting {n} with args.

Arguments starting with '@' are language keys; ISO dates ("2027-06-30") are shown with the localised month. Two placeholder forms serve grammar: "{n:di}" puts the Italian preposition and article before club name n ("della Roma", see ClubArticle), and "{n|one|other}" picks a word by whether argument n is 1 ("{0} {0|giorno|giorni}").

Detailed Description

League character of a match, set before kick-off with MatchEngine::setMatchContext(). The defaults are the calibrated engine and play exactly like an engine without a context.

Member Data Documentation

◆ goalRateScale

float MatchContext::goalRateScale = 1.0f

Finishing sharpness: above 1 more chances are converted (a high-scoring league), below 1 fewer (about 0.9 for a second tier). It acts on the precision of shots, not on the score, so shot volume and xG stay put.

◆ homeAdvantageScale

float MatchContext::homeAdvantageScale = 1.0f

Scales the home crowd's edge on attributes, execution and refereeing (0 = neutral venue).

◆ refereeStrictnessMean

float MatchContext::refereeStrictnessMean = 1.0f

Mean and spread of the per-match referee strictness drawn at kick-off; booking rates scale about linearly with it.

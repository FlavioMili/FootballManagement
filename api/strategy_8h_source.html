13/* TODO: These might later become a JSON file so that they can be modded
14 *
15 * DESCRIPTION OF ALL SLIDERS
16 *
17 * pressing : Team-wide intensity of pressing opponents (0 = none, 1 =
18 * maximum) riskTaking : Aggressiveness in attack vs. defensive caution (0 =
19 * very safe, 1 = very risky) offensiveBias : Likelihood to pass forward or
20 * safer options (0 = mostly safe, 1 = mostly forward) widthUsage :
21 * Horizontal spread of the team on the field (0 = narrow, 1 = full width)
22 * compactness : Closeness of players to the goalkeeper (0 = very close, 1 =
23 * very high)
24 *
25 * These sliders influence movement, positioning, passing decisions, and
26 * pressing behavior for all players during simulation. They can be
27 * combined with per-role weight maps for fine-tuned behavior.
28 */

16/* TODO: These might later become a JSON file so that they can be modded
17 *
18 * DESCRIPTION OF ALL SLIDERS
19 *
20 * pressing : Team-wide intensity of pressing opponents (0 = none, 1 =
21 * maximum) riskTaking : Aggressiveness in attack vs. defensive caution (0 =
22 * very safe, 1 = very risky) offensiveBias : Likelihood to pass forward or
23 * safer options (0 = mostly safe, 1 = mostly forward) widthUsage :
24 * Horizontal spread of the team on the field (0 = narrow, 1 = full width)
25 * compactness : Closeness of players to the goalkeeper (0 = very close, 1 =
26 * very high)
27 *
28 * These sliders influence movement, positioning, passing decisions, and
29 * pressing behavior for all players during simulation. They can be
30 * combined with per-role weight maps for fine-tuned behavior.
31 */

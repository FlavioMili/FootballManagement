Detailed Description

Shirt numbers of one match, handed out the same way by the 2D and 3D views: players wear their squad number. A player without one (an academy player called up) gets a free number: a goalkeeper one of the usual back-up keeper numbers, anyone else a spare number from 50 up, which squad numbers rarely reach. The squad numbers of the players in the match are reserved up front, so a call-up never takes a teammate's.

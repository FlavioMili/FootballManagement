Detailed Description

Central tuning values for the renderer-independent match simulation.

Keeping these values named and grouped makes balancing auditable and leaves a clean migration path to data-driven tuning profiles later. Normalized pitch coordinates use x for length (home attacks from 0 to 1) and y for width.

Detailed Description

Scene for managing application settings.

Appearance, audio, match, guidance and control changes apply at once (a live preview; Cancel restores them). Language and the display settings (resolution, frame cap, fullscreen, VSync) apply when the player presses Apply. Every row explains itself in a tooltip.

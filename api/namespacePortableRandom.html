Detailed Description

Distributions over any standard 32- or 64-bit generator (std::mt19937, std::mt19937_64), with the same results on every platform. Use these instead of the <random> distributions, whose algorithms are left to the standard library. The arithmetic lives out of line in world_rng.cpp.

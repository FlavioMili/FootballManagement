Detailed Description

Elementary functions built from IEEE-754 basic operations only (+, -, *, /, sqrt, frexp, ldexp, floor), which every platform rounds the same way. The C library's log, exp and cos may differ in the last bit between libstdc++/glibc, libc++/Apple and MSVC, which would make seeded draws platform dependent. Accurate to a few units in the last place.

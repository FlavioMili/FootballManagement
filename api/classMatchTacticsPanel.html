Detailed Description

Tactics dialog of the live match: style presets, the five instructions and the formation, edited as a draft and applied together.

The engine takes new instructions at once (the players re-form within a few seconds); a new shape costs some familiarity for a few minutes, which the dialog shows before applying. Every apply can be undone. In-match changes never alter the club's saved tactics.

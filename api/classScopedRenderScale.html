Detailed Description

Sets the SDL render scale for a scope and restores the previous one.

The SDL_Renderer ImGui backend only projects clip rectangles by the framebuffer scale; vertices stay in window coordinates. Drawing ImGui with the render scale set to DisplayFramebufferScale makes HiDPI outputs (Wayland scale 2, macOS Retina) fill the window instead of a corner.

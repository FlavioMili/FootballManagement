Detailed Description

ImGui/SDL-agnostic 2D tactical match renderer.

Draws the stadium surround, a lit and mown pitch with its markings and goals, top-down kit tokens (shirt, shorts ring, number, facing wedge), the ball with its shadow and trail, brief pass and shot paths, offside flashes and an optional pitch-control overlay into the current ImGui draw list. Consumes only the read-only snapshot and never touches the simulation; everything is interpolated with snapshot.interpolationAlpha.

Detailed Description

Physical outcome of one player's match.

  • end_condition < 0: the condition drain is estimated from minutes and stamina and the injury hazard is rolled here (ECIS match incidence).
  • end_condition >= 0: the match engine measured the condition and owns injuries; set injured=true for players it injured and the diagnosis and layoff are drawn here.

Detailed Description

Read-only normalized world state consumed by renderers.

The snapshot is rebuilt every frame from a MatchEngine and carries the previous and current fixed-step positions plus the interpolation fraction, so 2D and future 3D renderers can interpolate without touching the simulation. Renderers must never mutate this data or the engine.

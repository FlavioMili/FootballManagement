Detailed Description

Modal editor of the managed club's mentoring groups.

Self-contained: keep one instance in the hosting screen, call open() from a button and render() every frame. A senior player (25+) leads up to three youngsters (23 or younger); each group shows the personalities involved and how far the youngsters have moved so far.

Detailed Description

Selection rules of the league honours.

Player awards rank by average match rating plus a small bonus for goals, assists and (goalkeepers) clean sheets per appearance, among players with enough minutes; ties go to the lower player id so the result never depends on iteration order. Manager awards compare league points with the points expected from both line-ups (BoardModel::expectedPoints).

Detailed Description

Small fixed-size pool of background workers for batch work.

Workers run below the priority of the calling thread so background simulation never competes with the UI or other applications. parallelFor() lets the calling thread take part in its own batch, so it completes even when every worker is busy and cannot deadlock when called from a worker.

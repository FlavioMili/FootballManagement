Detailed Description

Design tokens shared by every management screen.

A theme is a preset palette plus one accent colour (the managed club's or a custom one). Typography uses the one bundled TTF at several sizes through ImGui's dynamic font atlas, and a small spacing scale keeps rhythm consistent between screens. Everything is re-applied live when the user changes appearance settings or the window moves to another display.

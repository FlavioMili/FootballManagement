Detailed Description

Per-career state of the guidance features: first-week checklist, delegation policy, opposition instructions and the analytics snapshots of the managed club's matches.

Persisted in GuidanceState, DelegatedDuties, OppositionInstructions and ManagedMatchAnalytics (assets/db/schema.sql) inside the game's save transaction.
